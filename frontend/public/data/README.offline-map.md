Place the offline PMTiles assets used by the scene chooser in this directory:

- `vietnam.pmtiles`
- `building-regions.json`
- `vn-buildings-*.pmtiles`
- `hanoi-wards.csv` (Hà Nội ward list for the scene-chooser ward search)
- `hanoi-wards.geojson` (simplified Hà Nội ward boundaries for the red
  boundary overlay)

The Docker frontend build checks for the base map, the building manifest,
both Hà Nội ward files, and at least one regional building PMTiles archive
before running `npm run build`.
The PMTiles files are large local assets and are intentionally ignored by git.
The ward CSV/GeoJSON files are generated by
`scripts/generate_vietnam_admin_csv.py` and
`scripts/generate_hanoi_wards_geojson.py` from the Vietnamese provinces
database and are tracked in git.
